# Agent Things (`/things`)

Run `/things` to open the interactive Agent Things progress card for the current Claude Desktop Code conversation. The card reads and writes the local Agent Things ledger. Task tools and conversational progress requests are provided by the companion `agent-things` skill and `session_status` MCP.
